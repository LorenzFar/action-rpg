# Action RPG Game

## Description
I have always had an interest in games, and this project was an opportunity to learn the fundamentals of game design through hands-on development. I decided to put together a simple action RPG using free pixel art assets and focused on building core gameplay mechanics. 

## Features
- Player movement and input handling
- Basic combat mechanics (attack, damage, cooldowns)
- Game state management (idle, combat, death)
- Simple enemy behavior and interactions

## What I learned ?
Through this project, I intentionally experimented with both GDScript and C++ to better understand their trade-offs, and deliberately forcing myself to use C++ even for relatively simple gameplay logic

I found that GDScript excels for rapid iteration and gameplay scripting due to its concise, Python-like syntax, while C++ is more suitable for complex, modular, and performance-critical systems where greater control and flexibility are required.
